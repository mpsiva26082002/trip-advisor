# Wayfare — Trip Advisor Style Clone

## About the Project

A front-end clone of a travel-discovery website (Trip Advisor style), built with plain HTML, CSS, and JavaScript. It includes a header with navigation, a hero search section, category browsing, featured destinations, hotels, restaurants, an awards banner, and a footer.
